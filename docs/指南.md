# CNI 使用与设计指南

[English](guide.en.md) · 中文

符号规则引擎：人话进、事实出。**无大模型**。

世界按解码表落盘：`isa` / `located` / `has` / `event`+`of(角色…)`。  
底层不把 `located`/`has` 改写成 `of(located,…)` / `of(has,…)`。

**分类与保留/删除以下表为准。** 表1逐条明细 → [规则全表.md](规则全表.md)。英文对照 → [guide.en.md](guide.en.md) / [rules.en.md](rules.en.md)。

## 表1：必须保留的规则（系统写死，共110条）

| 系列 | 编号范围 | 规则内容（核心逻辑） | 保留理由 |
| --- | --- | --- | --- |
| **D** | D1–D65 | 句法解析：主谓宾、把/被/兼/连/存现、复句、疑问、否定、省略、指代、情态等（共65条） | 拆句算法，用户无法自己补 |
| **E** | E1–E5 | 输入纠错：精确匹配、同音钉、错别字替换、多字删减（少字永不补） | 编辑距离/拼音匹配算法，用户无法自己补 |
| **F** | F41–F50 | 方言语序重排：“食先”→“先食”、“有V”→“曾V过”等10条 | 正则移位算法，不是查表，用户改不了 |
| **G** | G1–G10 | 实体归一化：“10w”→“100000”、“明天”→绝对日期、“几十”→“30”等 | 数学换算+系统时间戳注入，用户无法配置 |
| **I** | I1–I3 | 社交拦截：“谢谢/你好/再见”固定回复，不进入D系列 | 控制流决策；闭集为中文（英文问候靠表2 H 先映射） |
| **I** | I7–I8 | 标点压缩：“!!!”→“!”、“??”→“?” | 文本清洗算法 |
| **I** | I10 | 单字补全：“哦”→“我知道了”（补 other 为施事） | 默认主语补全，防止死锁 |
| **系统规则** | RO1–RO3 | 操作路由：教学触发、默认闲聊、失败不降级 | 引擎行为，用户改不了 |
| **系统规则** | WC1–WC3 | 世界一致性：重复忽略、矛盾并存、精准删除 | 数据管理逻辑，用户改不了 |
| **系统规则** | QP1–QP3 | 查询优先级：显式>推导>会话>日志、isa 链深2、疑问词固定角色 | 查询排序算法，用户改不了 |
| **系统规则** | MEM1–MEM3 | 记忆维护：focus 栈长度5、事件永久/会话临时、重置清空 | 内存管理算法，用户改不了 |
| **系统规则** | REN1–REN2 | 渲染兜底：缺模板裸显、空结果标准话术 | 输出回退逻辑，用户改不了 |

> **实现增补**（计入系统、不改上表110口径）：D66 / D67（内容存取）、I11（诗句拦截）。逐条见规则全表。

## 表2：完全删除、交给用户词典的规则（共54条）

| 系列 | 编号范围 | 原规则内容 | 删除后怎么交给用户 |
| --- | --- | --- | --- |
| **F** | F1–F40 | 网络缩写展开（yyds→永远的神）、方言词汇转写（偶→我）等40条 | 用户自行编辑 `user_dict.tm`，格式 `原文 → 标准词` |
| **H** | H1–H10 | 中英混合标准化（check→检查、update→更新、hello→你好）等 | 同上；**系统不直通英文**，英文只经词典换成中文后再进 I/D |
| **I** | I4–I6 | 表情转语气（😂→开心、😭→伤心、🤔→思考）共3条 | 用户自行在 `user_dict.tm` 中添加表情→语气映射 |
| **I** | I9 | “好吧”→“接受”语气映射 | 用户自定义语气词映射 |

## 执行总结

- **保留（写死）**：D/E/F41–50/G/I1–3/I7–8/I10/系统规则，共 **110条**，全部写进内核。
- **删除（交用户）**：F1–40 + H1–10 + I4–6 + I9，共 **54条**，不再内置，改为 `knowledge/user/user_dict.tm`。

**只按表1实现这110条**（外加已约定的 D66/D67/I11）；表2全部交给用户自己维护。

流水线：

```
输入 → E → user_dict(表2) → F41–50 → G → I(表1) → D → 内核(RO/WC/QP/MEM/REN) → 输出
```

## 设计架构

```
用户输入
    │
    ▼
┌─────────── RO 路由 ───────────┐
│  教/记住/学习/记 或 teach？     │
│   是 → hear（写）  否 → turn（读）│
└──────────────┬────────────────┘
               ▼
┌─────────── 预处理 ────────────┐
│  E → user_dict → F41–50 → G → I │
│  I 命中 → 直接口头回复，结束     │
└──────────────┬────────────────┘
               ▼
┌─────────── D 解码 ────────────┐
│  D66/D67 字面早退；否则 lex+D表 │
│  写 tell / 读 find·yesno       │
└──────────────┬────────────────┘
               ▼
┌─────────── 世界 ──────────────┐
│  isa / located / has / event… │
│  规则推理深≤2                  │
└──────────────┬────────────────┘
               ▼
┌─────────── REN 输出 ──────────┐
│  form/lex → 人话               │
│  REN1 缺模板裸显；REN2 查空话术 │
└───────────────────────────────┘
```

## 世界事实形态

```text
isa(电脑, 机器)
located(电脑, 桌上)          # 原生谓词
has(我, 电脑)                # 原生谓词
of(kind, e.1, invent)        # 事件角色仍用 of
of(content, 静夜思, 床前明月光)
```

## 怎么自己加知识

```bash
python -m cni teach "电脑是机器"
python -m cni reply "电脑是什么"
python -m cni teach "静夜思的内容是床前明月光"
python -m cni reply "静夜思的内容是什么"
```

表2：编辑 `knowledge/user/user_dict.tm`：`map 原文 标准词`。  
表1算法不靠改词典“补”；口语映射只加表2。

## 设计边界

- 无大模型；未教过的世界知识不猜
- 表1写死 / 表2用户维护，不混放
- 闲聊路径不写开放事实
- 落盘：`isa` / `located` / `has` / `of(角色…)`；不擅自加未声明谓词
- I11 不做诗词赏析
