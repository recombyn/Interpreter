符号规则引擎：人话进、事实出。**无大模型**。

世界按解码表落盘：`isa` / `located` / `has` / `event`+`of(角色…)`。  
底层不把 `located`/`has` 改写成 `of(located,…)` / `of(has,…)`。

**规则分工以下表为准。** 表1逐条 → [规则全表.md](规则全表.md)。英文 → [guide.en.md](guide.en.md) / [rules.en.md](rules.en.md)。

## 表1：内核规则（110）

## 分工与流水线

- **表1（内核）**：D / E / F41–50 / G / I1–3 / I7–8 / I10 / RO·WC·QP·MEM·REN，共 **110**；另加约定扩展 D66/D67/D69/MEM4/I11。

```
用户输入
    │
    ▼
┌─────────── RO 路由 ───────────┐
│  教/记住/学习/记 或 teach？     │
│   是 → hear（写）  否 → turn（读）│
└──────────────┬────────────────┘
               ▼
┌─────────── 预处理 ────────────┐
│  E → user_dict → F41–50 → G → I │
│  I 命中 → 直接口头回复，结束     │
└──────────────┬────────────────┘
               ▼
┌─────────── D 解码 ────────────┐
│  D66/D67 字面早退；短问 MEM4→D67；否则 lex+D表 │
│  写 tell / 读 find·yesno       │
└──────────────┬────────────────┘
               ▼
┌─────────── 世界 ──────────────┐
│  isa / located / has / event… │
│  规则推理深≤2                  │
└──────────────┬────────────────┘
               ▼
┌─────────── REN 输出 ──────────┐
│  form/lex → 人话               │
│  REN1 缺模板裸显；REN2 查空话术 │
└───────────────────────────────┘
```



## 世界事实形态

```text
isa(电脑, 机器)
located(电脑, 桌上)          # 原生谓词
has(我, 电脑)                # 原生谓词
of(kind, e.1, invent)        # 事件角色仍用 of
of(content, 静夜思, 床前明月光)
# D67：按实体 O(1) 取 content（内存索引 ∪ knowledge/user/.content 分片）
# MEM4：短追问 + 实体钉 → 补全为 D67（无开放检索规则）
```

## 用户层 tm 语法



### 符号总表


| 符号 / 行首                                   | 出现在                                                | 含义                                   |
| ------------------------------------------ | --------------------------------------------------- | ------------------------------------- |
| `# …`                                     | 几乎所有 `.tm`                                         | 注释，引擎忽略                              |
| （空行）                                      | 任意                                                 | 无语法意义，可忽略                            |
| `! 名字 : e`                                | 记忆世界（`劳动法.tm`、`limits.tm`、`labor_law.tm`、runtime…） | **登记实体**：论域里出现这个名字；`e` = entity      |
| `+ isa(A, B)`                             | 同上                                                 | **写入事实**：A 是 B（类属）                   |
| `+ has(A, B)`                             | 同上                                                 | A 有 B（领属）                            |
| `+ located(A, B)`                         | 同上                                                 | A 在 B（位置）                            |
| `+ of(键, …)`                              | 同上                                                 | 通用槽位事实（content / 上限 / 单位 / 出处 / 许可…） |
| `rule …`                                  | **仅** `rules.tm`                                   | D69 判定声明（主题、算子、触发词）                  |
| `tier …`                                  | **仅** `rules.tm`                                   | D69 多档上限（如合同期限→试用期）                  |
| `map 原文 标准词`                              | **仅** `user_dict.tm`                               | 预处理替换（表2词典）                          |
| `out 名 表面`                                | **仅** `form.tm`                                    | 覆盖输出话术                               |
| `reply_mode` / `judge_cite` / `default` … | **仅** `config.tm`                                  | 配置项，不是世界事实                           |
| `（空行）`（作为名字）                              | 由 `*.text` 同步生成的 `*.tm`                            | 原文空行的占位实体名/正文                        |


记忆世界：先 `!` 再 `+`。`rule` / `map` / `out` 与记忆世界行分属不同文件格式。

### 记忆世界（`!` / `+`）

`劳动法.tm`、`labor_law.tm`、`limits.tm`、对话 teach 写入的事实共用上表。谓词限于已支持者（含 `上限/下限/许可/出处/单位` 等）。

### `*.text` 与同名 `.tm`


| 文件                     | 作用                                                                |
| ----------------------- | ------------------------------------------------------------------ |
| `*.text`（如 `劳动法.text`） | 按行原文                                                              |
| 同名 `.tm`               | 由 `python -m cni.tools.sync_user_docs`（可加 `--force`）生成；供 D67 按行回显 |


- 每行对应实体 `第N行` 与 `{文档名}第N行`  
- 原文空行登记为占位名 `（空行）`，行号对齐  
- 长正文在 `.content/` 分片；`.tm` 为实体与索引



### `labor_law.tm`

可选小规模 `isa` / `has` / `content` 概念图（评测等可经 `memory_path` 加载）。与整部法逐行索引的 `劳动法.tm` 不同。阈值判定见 `rules.tm` + `limits.tm`。

### `rules.tm`（D69）

不进入普通世界事实扫描；由判定模块读取。

```tm
# rule {主题} {算子} {关系键[&附加键…]} {触发1|触发2|…}
# tier {主题} {合同月下限含} {合同月上限不含|0=+∞} {试用期上限月数}
# 算子: le / ge / eq / in
# 关系键: 上限 / 下限 / 许可

tier 试用期 3 12 1
rule 试用期 le 上限 合法吗|合规吗|可以吗
rule 试用期 le 上限&书面约定 严格合法吗
rule 合同类型 in 许可 合法吗|合规吗|可以吗
```


| 字段     | 含义                                |      |
| ------- | ---------------------------------- | ----- |
| 主题     | 与 `limits.tm` 中 `of(…, 主题, …)` 一致 |      |
| 算子     | `le`≤ · `ge`≥ · `eq`= · `in` 枚举成员 |      |
| 关系键    | 对应 limits 中的 `of` 键               |      |
| `&附加键` | 合取：另须存在 `of(附加键, 主题, …)`          |      |
| 触发     | 问句尾匹配，`                           | ` 分隔 |
| `tier` | 合同期限落在 下限, 上限) 月 → 该档试用期上限        |      |


`limits.tm` 为记忆世界格式（见符号总表）。可由 `python -m cni.tools.compile_limits --write` 从法条抽「不得超过…」生成。

## 对话记忆（会话钉，不是知识库）

原则：**把「当前在谈哪份文档 / 哪个实体 / 哪个主题」钉清楚，短问自动接上这些钉；知识仍在世界与 content 库，会话只负责指代与消歧。**


| 钉              | 含义           | 谁用                       |
| --------------- | ------------- | ------------------------- |
| `doc_focus`    | 当前文档（如`劳动法`） | 裸`第N行` → 优先`劳动法第N行`（D67） |
| `entity_focus` | 当前实体         | 这/那/他；MEM4 短问 → D67      |
| `topic_focus`  | 近期正文词        | 会话上下文标记（不单独检索）           |
| `event_focus`  | 事件`e.n`      | 事件指代                     |


- **D66/D67** 读写 content（世界 ∪ `.content` 分片）  
- **MEM4** 短追问（`那呢`/`违法吗`…）有实体钉 → 补成`{实体}的内容是什么` → D67  
- **无 D68**：没有解出实体就不开放检索，走 REN2 / 常规未命中



## 已知能力边界（D 层）

Interpreter 的 D1–D65 是**句式模板匹配**，不是完整依存句法。长难嵌套、倒装、多层兼语容易误匹配；普通 D 组同句多解时默认取第一条（`ambig_mode first`）。**D67/D69 查询**可在一句内多次命中（MULTI），按子句跨度分别作答。

已落地的缓解：


| 项 | 做法 |
| ---- | ---- |
| 多规则歧义 | `config.tm` → `ambig_mode clarify\|warn\|first`（AMB1 反问 / 降置信） |
| 意合复句 | 无连词的 `A，B` 启发为 `cause`/`before`（D37y / D40y，与显式连词同关系名） |
| 阈值判定 | **D69**：`rules.tm` + `limits.tm`；`compile_limits` 半自动抽上限；缺值追问 `D69.ask`；`in 许可` 枚举 |
| 同句多查 | **MULTI**：扫描多个 D67/D69 子句分别作答（句式跨度命中，非问号硬切）；答案用 `；` 拼接；长前缀可剥出句中查询 |
| 共指 | MEM5：`last_patient` / `coref_chain`；`他/她` 优先受事 |
| 否定 | 写库不存「否定事件」；查询走 D57/D58 翻转，与事实否定分离 |
| 实体消歧 | 仍无百科链接；靠 focus / doc_focus / 用户教名 |




## 回复话术（form.tm）

**原则**：D 只产出参数；表面一律由 `form.tm` 拼（用户键覆盖系统）。

判定问（D69）：理解触发词/词干后填槽 → `polar.<词干>.yes|no` → `polar.default.*` → `{clause}{pred}`。  
例：`试用期半个月合法` / `试用期七个月不合法`。

| 参数 | 含义 |
| --- | --- |
| `{clause}` `{stem}` `{pred}` | 情况 / 词干 / 变形谓词 |
| `{topic}` `{trigger}` | 主题 / 命中触发 |
| `{yes}` `{no}` | 全局是非（也受 `reply_mode` 影响） |

```tm
out polar.default.yes {clause}{pred}
out polar.合法.yes 是
out polar.mode short
out yes 是
out no 否
out unknown_q 暂无资料
```

`reply_mode`（`config.tm`）只 remap `yes`/`no`；D67 仍回正文。

### 阈值判定（D69）

语法见上文 **「用户层 tm 语法」**。示例：

```tm
# knowledge/user/rules.tm
rule 试用期 le 上限 合法吗|合规吗|可以吗
rule 合同类型 in 许可 合法吗|合规吗|可以吗
# 合取示例: rule 试用期 le 上限&书面约定 合法吗
# 多档: tier 试用期 3 12 1
```

```bash
python -m cni.tools.compile_limits --write   # → knowledge/user/劳动法/limits.tm
python -m cni reply "试用期六个月合法吗"     # D69 → 是的（见劳动法第84行）
python -m cni reply "合同一年试用期二个月合法吗"  # 多档：一年档上限2月
python -m cni reply "试用期合法吗"           # D69.ask → 请问试用期几个月？
python -m cni reply "六个月"                 # 续答 → D69
python -m cni reply "试用期六个月严格合法吗" # 合取：需 of(书面约定,…)
python -m cni reply "合同类型固定期限合法吗" # 枚举许可
```

`config.tm`：`judge_cite on|off` 控制是否附出处。  
无上限/许可事实 → REN2。不是开放全文检索。

## 设计边界

- 无大模型；未教过的世界知识不猜
- 表1内核 / 表2用户词典，不混放
- 闲聊路径不写开放事实
- 落盘：`isa` / `located` / `has` / `of(角色…)`；不擅自加未声明谓词
- I11 不做诗词赏析
